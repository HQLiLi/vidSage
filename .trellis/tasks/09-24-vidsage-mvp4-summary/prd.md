# MVP-4 结构化总结 — PRD

> Epic 路线图见 `../09-24-vidsage/prd.md`，分段压缩思路见主项目 0007 上下文工程。
> 实现参考（本地开源项目源码索引）见 `../09-24-vidsage/research/oss-references.md` 第三节 MVP4 小节；规划期（Phase 1.3）应把它挂入本任务的 `implement.jsonl` 与 `check.jsonl`。

## 范围

1. 结构化总结：要点、章节、关键结论。
2. 长字幕分段压缩（map-reduce：分段摘要 -> 汇总）。
3. 总结结果结构化落盘（JSON），进度接入 SSE。

## 不做

- 前端展示页面的精细化（可用最简页面/接口返回验证）。
- 时间戳问答、向量化（阶段二）。

## 验收标准

- [ ] 输入翻译后字幕，产出含要点 + 章节的结构化总结。
- [ ] 长视频（>30 分钟字幕）走分段压缩路径不超上下文限制。
- [ ] MVP 全链路（提交 -> 字幕 -> 翻译 -> 总结）端到端真实运行一次，勾掉 epic 验收标准第 1、2 条。
