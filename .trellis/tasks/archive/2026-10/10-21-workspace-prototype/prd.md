# 工作区页原型：新布局与交互验证（假数据）

> 父任务：`10-21-workspace-page-revamp`。本子任务只动 `prototype/`，**不碰 `frontend/`**。

## Goal

在 `prototype/` 沙盒里用假数据把工作区页的新布局搭出来，验证分区、比例与交互是否成立。
验证通过后，由子任务 `10-21-workspace-fe-rewrite` 按它重写进 `frontend/`。

## Requirements

- **R1 新布局**：顶栏保持不动；其下左右分栏，左侧视频区与右侧字幕区宽度比为 **3:2**。
  - 顶栏左侧入口文案为「返回」。
  - **左侧视频区，垂直分三块**：① 视频 / 音频播放器 ② 用户自定义关键词列表，标题行右侧是「重新生成」 ③ 主题区，显示媒体主题。
  - **右侧字幕区维持原样**（标题 + 计数、搜索框、时间码 + 原文 + 译文列表、点击 seek、自动滚动跟随）。每条字幕在 hover / 聚焦时右上角显示修改图标，点击后进入该条的原文修正。
- **R2 假数据形状镜像真实契约**：mock 数据的字段形状必须与后端实际产出一致，否则"看着对"没有意义。具体形状见 `design.md` §3。
- **R2.1 播放器尺寸稳定**：播放器高度由固定 16:9 比例决定，不随关键词或主题内容增减而缩放。
- **R3 关键交互可点**：关键词增 / 删、点「重新生成」、字幕搜索与 seek、字幕行 hover 修改图标与该条行级编辑态。
- **R4 首轮只做就绪态**：固定展示“清洗结束”的主页面，不提供状态切换器。第一轮验收通过后，再追加 SSE / 进度 / 失败态原型。
- **R5 上传页不动**：`prototype/src/views/UploadView.vue` 与 `App.vue` 的入口逻辑保持原样。
- **R6 技术栈自由**：原型不要求使用 Vue，也不受正式前端规范约束；优先选择最快、最方便的实现方式。当前 Vue 脚手架可复用，但不是绑定条件。
- **R7 翻译入口与语种选择**：右侧字幕区加入主流翻译器式的语言控件：源语言 select、互换按钮、目标语言 select、翻译按钮。
  - 语种清单镜像 `GET /api/languages` 的 `{code, label}` 形状，原型内置简体中文 / 繁体中文 / 英语 / 日语四项。
  - 源语言默认取 `context.sourceLanguage`，目标语言默认英语；进入就绪页时默认**不翻译**，不展示旧译文。
  - 两个 select 共用同一清单；源语言与目标语言相同时禁用翻译按钮，并说明原因。
  - 翻译按钮触发的进度、完成与译文切换均为本地模拟，不写任何真实网络请求；完成后显示当前目标语种的双语字幕。

## Acceptance Criteria

本子任务产出**不进 git**（`/prototype/` 已 gitignore），因此验收方式是**跑起来看**，不是看 diff。

- [x] **AC1** `cd prototype && npm run dev` 能起来，首页照旧，进入工作区后是新布局。
- [x] **AC2** 左侧视频区与右侧字幕区按 **3:2** 分栏；关键词列表允许明确的内部滚动，除此之外不做无意义的嵌套滚动。桌面端滚动条默认隐藏，仅在悬停 / 滚动对应区域时显示细滚动条，常见视口下内容不能塌缩或裁切。
- [x] **AC3** 视频块能真的播放 `public/demo/lecture.mp4`；音频任务形态（`podcast.mp3`）同样成立。
- [x] **AC4** 关键词区用限高垂直列表展示并可内部滚动，能增、能删，列表为空时有明确空态；「重新生成」在列表为空时按钮语义清楚（对应后端 `[]` = 清空重跑）。
- [x] **AC5** 主题区显示一两句话的主题；通过原型专用演示参数切到 `degraded` mock 时，看到的是明确文案而非空白。
- [x] **AC6** 字幕区的搜索、点击 seek、当前句高亮、自动滚动跟随全部照旧可用。
- [x] **AC7** 字幕行 hover / 聚焦时右上角出现镂空修改图标；点击只编辑该条原文，能保存到本地内存或取消退出；保存动作**明确标注后端未实现**，不假装成功。
- [x] **AC8** 窄屏（< 1024px）下上下堆叠，三块与字幕区都能滚到，无内容被裁掉。
- [x] **AC9** 首轮固定为清洗结束的就绪态，不出现误导性的进度 / 失败切换控件；SSE 与非就绪态留到第一轮验收后的下一轮。
- [x] **AC10** 字幕区可见源语言 / 目标语言两个 select、互换按钮和翻译按钮；四项语种均来自同一 mock 清单，窄宽度下不溢出。
- [x] **AC11** 初始进入就绪页时默认不翻译、不出现译文行；可切换语种，源语言与目标语言相同时翻译按钮禁用并有明确提示。点击翻译后出现本地模拟进度，完成后双语字幕切到所选目标语种，且页面明确标注“本地演示 / 未发起请求”。
- [x] **AC12** 重新生成字幕会令旧译文失效，翻译入口保持在位并可直接重新翻译；主任务处理中翻译控件不可误触。

## 不做什么

- 不写任何真实网络请求（本子任务全程假数据）。
- 不碰 `frontend/`。
- 本轮不解决 SSE / 契约错位；第一轮验收通过后追加 SSE 原型，真实契约接入仍属于 B。
- 不做视觉稿级打磨（配色 / 字体沿用现有 token 即可，重点是**结构与交互**）。
