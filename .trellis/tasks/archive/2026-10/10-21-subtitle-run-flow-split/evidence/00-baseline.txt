## 首跑：被污染的数字（缺 gitignored 的本地配置）

```
[ERROR] Errors:
[ERROR]   VidSageApplicationTests.contextLoads » IllegalState Failed to load ApplicationContext ...
[ERROR] Tests run: 700, Failures: 0, Errors: 1, Skipped: 1
[ERROR] BUILD FAILURE
```

根因（surefire 报告里最深一条 `Caused by`）：

```
Caused by: org.springframework.boot.jdbc.autoconfigure.DataSourceProperties$DataSourceBeanCreationException:
    Failed to determine a suitable driver class
```

**`application-local.yml` 被 `.git/info/exclude` 排除，新工作树不会带它**——而 `VidSageApplicationTests`
显式标了 `@ActiveProfiles("local")`（该测试类自己的 Javadoc 写了原因：不激活则数据源配置不加载，
全量上下文必以「Failed to determine a suitable driver class」失败）。补文件后即恢复。

```bash
cp /f/personal_project/vidSage/backend/src/main/resources/application-local.yml \
   <worktree>/backend/src/main/resources/application-local.yml
```
