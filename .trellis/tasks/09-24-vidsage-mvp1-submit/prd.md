# MVP-1 任务提交与异步管线 — PRD

> Epic 路线图见 `../09-24-vidsage/prd.md`，技术方案见 `../09-24-vidsage/design.md`。

## 范围

只做「任务进入系统」这一段，不含实际下载/转写/翻译：

1. 任务提交接口：B站 / YouTube 链接或本地视频、音频文件。
2. 任务实体落库（MyBatis-Plus），任务状态机（如 PENDING / RUNNING / FAILED / DONE）。
3. SSE 进度推送端点（复用 0009 经验），状态变更时推送。
4. 异步执行骨架：提交后进入异步处理（本阶段可以为空实现/占位阶段）。

## 不做

- 下载、字幕、翻译、总结（后续子任务）。
- 用户体系 / 权限。

## 验收标准

- [ ] 提交链接或本地文件后，任务持久化并可查询状态。
- [ ] SSE 端点能实时推送任务状态变更。
- [ ] 非法输入（不支持的链接/格式）返回明确错误。
- [ ] 至少一条真实运行证据（learning-records）。
